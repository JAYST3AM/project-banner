## Acceptance contracts (evidence required, not assumed)

**E3 activation/legality:** With `PB_GPU_TERRAIN_BACKEND=1`, a real **windowed** battle must report `GPU terrain ACTIVE` after deterministic deployment repair. No second `BattlefieldTerrain` is generated by the GPU backend. The source identity and terrain signature must match the `BattleSimulator.terrain` read by `BattleView`; intentional terrain-source mutation must fail closed. An impossible legal-deployment plan or unavailable Vulkan GPU must fail with an explicit error, not switch silently to the CPU mode. Normal CPU mode is unchanged when the flag is off.

**E3 collision runtime:** E2 shader mode 6 runs a batch for the real battle's proposed positions and writes adjusted positions back to `BattleSimulator` and its native grid mirror. On hardware compare outputs against `BattleTerrainGpuMask.slide` for every case in the purpose-built windowed fixture. The GPU adapter frees its uniform set, pipeline, shader and all 15 owned storage buffers with no RID leak warnings.

**DIRECTIVE-001:** The LOD review above is the decision. Any future attempt at simulation LOD requires deterministic soldier-level outcomes, performance evidence and no concurrent GPU capture. No CPU simulation LOD was enabled in this batch.

**Fixture integrity:** Targeted `test_runner_contract` requires the six intentionally broken/healthy fixture Git blob hashes to match their certified LF contents and proves none is part of the normal 48-suite registry. Deliberately edit one fixture in a throwaway worktree and require a failing integrity assertion; restore the file afterwards. This is a concrete negative-fixture integrity repair, **not** a claim that an unspecified broader Playable Alpha fixture checklist has been certified.

**Windowed integration:** Run `godotc --path <isolated-branch> res://scenes/dev/gpu_campaign_terrain_smoke.tscn -- --out=<writable-png-path>`.
