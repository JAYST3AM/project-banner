# Project Banner — settlement sprite list

Generated by `tests/test_sprite_list.gd` from the building catalogue (D-138): 160 towns
planned with the real generator, every appearance counted. Regenerate rather than hand-edit.

**Style (the owner's art direction):** crisp pixel art, strong dark outlines, readable
silhouette, isometric / elevated perspective, grounded medieval look, slightly stylized
proportions, one consistent light direction, controlled palette, clear roofs, clear timber
framing. Avoid: overly clean repetition, generic fantasy exaggeration, excess gold,
identical proportions, visual noise, details that vanish at gameplay scale.
**Rule of the programme:** the system comes first. Draw bases + one material set + one
condition overlay first; the breadth (every biome, every attachment) is a later pass.

**Budgets over these 160 towns** — grounds: Forest x56, Coastal x24, Highlands x40, Arid x8, Plains x32 · purposes: farming x28, fishing x12, mining x20, market x20, military x80
